# DSE 數學 · 主項變換操練

香港中學文憑試（DSE）數學卷一「主項變換」互動操練工具。單頁 HTML／JavaScript，用瀏覽器直接開啟。

## 功能

- 自動生成貼近 DSE 風格的主項變換題目（12 種題型模板，數字／字母可隨機）
- **逐步拖拉**：每一步拖入正確的下一式（KaTeX 排版）
- **Equation editor**：分數、根號、上標等工具列，可自行砌最終答案
- 即時對錯回饋與詳解
- 記錄答對率與錯題類型

## 快速開始

1. 用瀏覽器開啟 [`index.html`](./index.html)（或 `主項變換操練.html`）
2. 需要上網載入 [KaTeX](https://katex.org/)（CDN）以顯示數式

本地預覽：

```bash
npx --yes serve .
# 或 python3 -m http.server 8080
```

## 題型模板（現有 12 類）

1. 一次式移項除係數  
2. 去括號／分配律逆向  
3. 分式兩邊乘分母  
4. 倒數關係  
5. 物理公式（勻加速）  
6. 物理公式（平均速率）  
7. 開方求主項（圓面積）  
8. 光學公式（透鏡）  
9. 溫度換算公式  
10. 點斜式改寫  
11. 開方（電功率）  
12. 比例式改寫  

## 之後可加的方向

- 擴充題庫（二次式、複合根號、較長 DSE 長題）
- 離線打包 KaTeX（唔使 CDN）
- 進度儲存／帳號
- GitHub Pages 公開練習連結
